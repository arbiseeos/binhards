# Contributing

## Formatting

BinHardS uses repository-level formatting rules so contributors can use different editors without changing the project's style.

### Rust

Use rustfmt through Cargo:

    cargo fmt --all
    cargo fmt --all -- --check

### TOML

Use Taplo 0.10.0:

    cargo install taplo-cli --version 0.10.0 --locked
    taplo fmt
    taplo fmt --check --diff

`Cargo.lock` is generated by Cargo and is intentionally excluded from the Taplo formatting check.

### Markdown and YAML

Use the repository's Prettier configuration with Prettier 3.9.9:

    npx --yes prettier@3.9.9 --write "**/*.{md,yml,yaml,json,jsonc}"
    npx --yes prettier@3.9.9 --check "**/*.{md,yml,yaml,json,jsonc}"

The authoritative Prettier settings are in `.prettierrc.json`.

### Before opening a pull request

Run:

    cargo fmt --all -- --check
    cargo clippy --all-targets --all-features -- -D warnings
    cargo test --locked --all-targets
    cargo package --locked
    taplo fmt --check --diff
    npx --yes prettier@3.9.9 --check "**/*.{md,yml,yaml,json,jsonc}"

CI runs the same formatting checks. Formatting failures should be fixed in the contributor's branch rather than bypassed in CI.
